# 行动者六要素 · 生命操作系统

> 以马克思-黑格尔逻辑学为底层的个人行动体系 · 独立网站 + Obsidian 知识库 + 视频识别流水线

## 这是什么

一套完整的个人行动系统，来源是两张手写笔记照片：

- **四个附着的主题**：时间（生命）· 健康 · 钱 · 人际关系
- **两个最根本的能力**（需灵活运用）：爱欲 · 理性
- 每晚抖音直播「行者夜话」：讲解全部行动路径、人生方向、学习内容、限时解决问题小技巧

## 快速开始

### 1. 打开网站

双击 `index.html`（任何电脑/手机浏览器都可以，不需要联网、不需要安装任何东西）。

- 电脑视图 / 手机视图自动适配
- 六要素卡片点击展开
- 逻辑学思维导图：拖拽平移、滚轮缩放、点节点看详情、可切换大纲视图、可搜索
- 未明子视频研究：按分类筛选，展开完整要点与落地报告
- 直播脚本生成器：输入主题 → 生成结构化直播脚本
- 每日打卡：九项日课，连续全勤累计「行动力火焰」
- 倾诉树洞：本地存储 + 站长后台（密码保护）

### 2. 站长后台（树洞管理）

网站右下「暖心驿站」→「站长后台」：

1. 首次使用：设置后台密码（仅存 SHA-256 哈希于本设备）
2. 收件箱：查看全部倾诉 → 标记状态 → 写回信 → 删除
3. 导出/导入 JSON 备份
4. 开启浏览器通知（新投稿即时提醒 + 每晚 21:00 直播提醒）
5. **跨设备同步（可选）**：填 GitHub Token + 私有仓库（owner/repo）→ 新投稿同步为 Issue → **手机 GitHub App 即时收到推送**，数据存在你自己的账号
6. 设置站长邮箱（「发送邮件倾诉」按钮的收件人）

### 3. Obsidian 知识库

把 `obsidian-vault/` 整个文件夹拖进 Obsidian 作为仓库打开：

- `00-知识库索引.md` 是总入口
- 所有笔记带 `[[]]` 双链（正文中提到其他章节自动成链）
- `黑格尔逻辑学.canvas` 是画布思维导图（ Obsidian 左侧 Canvas 打开）

### 4. 更新内容

编辑 `data/*.json` → 运行 `python build.py` → 重新生成 `index.html` 与知识库。

## 隐私承诺

- 网站是**单文件**，没有任何服务器、没有任何追踪、不依赖 CDN
- 树洞投稿、打卡、后台数据全部存于浏览器 localStorage（仅本设备）
- 备份导出由用户亲手掌握

## 已知限制 / 后续路线

1. 树洞跨设备实时互通需要一台服务器（当前方案：本地后台 + 邮件 + GitHub Issues 通知三通道）
2. B站 CC 字幕需登录态（已内置 ASR 兜底，无需登录）
3. 直播时间默认 21:00，在 `data/framework.json` 的 `livestream` 中修改
4. 站名/格言/邮箱均在 `data/framework.json` 与后台设置中可改
